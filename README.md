## Utilities
- hyprland   - Window Manager
- awww       - Wallpaper Manager
- hyprlock   - Lock Screen
- hypridle   - Locks Screen When Idle
- kitty      - Terminal
- nvim       - IDE
- rofi       - Application Launcher & Other Menus (swapped to quickshell)
- swaync     - Notification Daemon (looking to swap to quickshell)
- waybar     - Status Bar (swapped to quickshell)
- wlogout    - Logout Menu (looking to swap with quickshell)
- quickshell - Toolkit for building environments
